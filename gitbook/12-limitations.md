# Limitations & Non-Claims

{% hint style="danger" %}
Please cite this section whenever quoting platform outputs.
{% endhint %}

## Scientific limitations

* Short Indus texts limit morphological and syntactic tests
* Sign inventories and directions can be uncertain
* Comparative corpora differ in genre, length, and period
* Embedding / vision similarity is geometric, not semantic
* Demo quantitative results may use synthetic data
* Speculative lexicon frames are pedagogical, not peer-reviewed etymologies

## Explicit non-claims

1. Indus has **not** been deciphered by this software
2. Meluhha ≠ proven Indus language identity
3. JS divergence ≠ genetic relatedness
4. Glyph motif names ≠ established sign meanings
5. English sentences in the lab ≠ attested Indus readings
6. High hypothesis triage scores ≠ independent validation
