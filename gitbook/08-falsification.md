# Falsification Framework

{% hint style="danger" %}
**Mandatory.** Apparent similarities that random or frequency-preserving nulls can reproduce must **penalise** a hypothesis.
{% endhint %}

## Null models implemented

| Control | Purpose |
| --- | --- |
| Frequency-preserving shuffle | Break sequential structure; keep inventory frequencies |
| Random inventory draws | Length-matched nonsense sequences |
| Length-matched donor control | Indus lengths filled from comparison tokens |
| Permutation tests | Empirical p-values for JS / mutual information |
| Bootstrap CIs | Uncertainty on null summaries |
| Benjamini–Hochberg FDR | Multiple-testing correction |
| Cross-validated JS | Stability across folds |
| Negative controls | Random-vs-random baselines |

## Interpretation guide for examiners

* **Fail to reject null** ≠ proof of unrelatedness
* **Reject null** ≠ decipherment or shared ancestry
* University theses should report the full falsification table beside any positive structural finding
