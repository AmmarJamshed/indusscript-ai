# Why Universities Should Engage

## Academic value proposition

IndusScript AI is positioned as **research infrastructure**, analogous to a shared lab bench:

| Stakeholder | Value |
| --- | --- |
| Linguistics / CL departments | Reproducible labs on entropy, n-grams, embeddings with ancient data ethics |
| Archaeology / Ancient Near East | Meluhha & trade-graph modules tied to primary-text citation practice |
| Digital humanities centres | Provenance registry + public responsible demo |
| Statistics / data science | Falsification, FDR, bootstrap case study with cultural stakes |
| University communications | Outreach that models scholarly caution instead of viral “deciphered!” claims |

## Justification checklist for research offices

* [x] Explicit non-decipherment policy in UI, API reports, and this paper
