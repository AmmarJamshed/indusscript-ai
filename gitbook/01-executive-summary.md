# Executive Summary for Universities

{% hint style="info" %}
**One sentence.** IndusScript AI is not a decipherment product; it is a **reproducible experimental apparatus** for testing whether comparative evidence can support, weaken, or falsify candidate readings of Indus inscriptions.
{% endhint %}

## The problem universities face

Claims about Indus “translations” circulate faster than peer review. Departments need a platform that:

* Separates **visual**, **structural**, **contact**, and **semantic** questions
* Records **licence and provenance** for every dataset
* Penalises hypotheses that random controls can reproduce
* Shows speculative English glosses only with **evidence tiers** and assumptions

## What IndusScript AI delivers

| Deliverable | Academic use |
| --- | --- |
| Unified historical data model | Shared schema for seminars / theses |
| Source registry | Compliance with data ethics & redistribution rules |
| Comparative engines | Course labs in corpus linguistics / information theory |
| Meluhha evidence DB | Bronze Age contact modules in archaeology |
| Hypothesis + falsification suite | Method training against overclaiming |
| Public Pages lab | Outreach without implying decipherment |
| Open GitHub repository | Reproducible citation and forkable coursework |

## Recommended institutional adoption path

1. **Seminar pilot (4–6 weeks):** students run frequency / n-gram / falsification notebooks on the demo corpus
2. **MA/MPhil methods chapter:** replace synthetic rows with licence-cleared CDLI/ORACC/TLA subsets
3. **Lab collaboration:** epigraphers validate sign inventories; statisticians stress-test null models
4. **Public scholarship:** link the GitHub Pages lab with this white paper’s integrity banners

## Non-negotiable claims (what we will not say)

* We do **not** assert Proto-Dravidian, Munda, Indo-Aryan, or isolate identity as proven
* We do **not** equate Meluhha with “the Indus language”
* We do **not** treat CLIP/JS/embedding proximity as semantic proof
* We do **not** publish fluent English as an attested Indus translation
